# Progenerator — Company and Team Fit

Potential skills fit only, not product adoption, endorsement or partnership.

## Project thesis

A project idea explorer that searches public GitHub repositories for a topic and uses AI to suggest possible gaps or new directions.

## GitHub

**Relevant technical areas:** Developer platform, code search and open-source discovery.

**Potential roles:** Developer Tools Engineer, AI Product Engineer, Full-stack Engineer, Search Engineer or Applied ML Engineer.

**Evidence:** Static browser frontend using public GitHub repository search and a user-provided DeepSeek key for idea generation. It presents repository metadata and generated project suggestions. Search results are incomplete and generated ideas require human verification; the tool does not prove novelty or market demand.
